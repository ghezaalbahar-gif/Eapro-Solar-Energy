## 🌱 About the Project

**Eapro Solar Energy** is a frontend web project designed around the solar energy industry. It provides an engaging and responsive interface for presenting renewable energy solutions and information.

The project focuses on:

* ☀️ Solar and renewable energy
* 🌱 Sustainability
* 📱 Responsive web design
* 🎨 Modern UI/UX
* ⚡ Clean and organized frontend development

## ✨ Features

* Responsive design for desktop, tablet, and mobile

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

```bash
git clone https://github.com/ghezaalbahar-gif/Eapro-Solar-Energy.git
```

2. Open the project folder:

```bash
cd Eapro-Solar-Energy
```

3. Open `index.html` in your browser.

No additional installation or dependencies are required.
